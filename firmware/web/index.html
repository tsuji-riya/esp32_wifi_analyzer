チャンネル混雑度

バー: 重なる AP の電波強度から算出した干渉スコア / 線: 受信フレーム数 (fps)。 フレーム数はスキャン中に滞在したチャンネルで計測するため、AP の待受チャンネルは多めに出ます。

信号強度の推移 (★ を付けた AP、未選択時は上位 5 件)

接続先はデータフレーム / アソシエーション要求の BSSID、探索 SSID はプローブ / アソシエーション要求に含まれる SSID です。 「ランダム」はローカル管理ビットが立った (プライバシー用) MAC アドレスです。

端末が過去に接続したネットワークを探すために送る SSID の集計です。「付近に存在」は同名 AP を検出済みかを示します。

Deauthentication / Disassociation フレームの直近 32 件。短時間に大量に出る場合は切断攻撃や不安定な AP の可能性があります。
